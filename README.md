# Pre-Pleating 🪡

A premium landing page for a bespoke saree pre-pleating tailoring service based in Bhavani, Erode, Tamil Nadu. Built with a focus on elegant design, smooth animations, and a seamless booking experience.

## ✨ Features

- **3D Scroll Animations** — Aceternity-inspired card reveals with perspective transforms driven by `requestAnimationFrame`
- **Masonry Portfolio Grid** — Filterable gallery with glassmorphism hover overlays
- **Booking Form** — Integrated with Google Sheets as a backend via Google Apps Script
- **Snackbar Notifications** — Custom animated success/error feedback on form submission
- **Scroll Reveal** — Smooth fade-in animations for all content sections
- **Lightbox** — Click-to-expand image viewer for the portfolio
- **Mobile Responsive** — Fully responsive layout with a collapsible mobile navigation menu
- **FAQ Accordion** — Animated accordion for frequently asked questions
- **Bot Protection** — Honeypot field on the booking form to filter spam

## 🛠️ Tech Stack

| Technology | Version | Purpose |
|---|---|---|
| HTML5 | 5 | Semantic structure |
| Tailwind CSS | 4.x (CLI) | Utility-first styling |
| Vanilla CSS | 3 | Custom animations, gradients, component styles |
| JavaScript | ES6+ | DOM manipulation, scroll logic, form handling |
| Phosphor Icons | Web CDN | Iconography |
| Google Fonts | Latest | Inter (sans-serif), Playfair Display (serif) |
| Google Sheets | Apps Script | Form submission backend |

> **No frameworks.** No React, no Vue, no jQuery. Pure vanilla stack.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [pnpm](https://pnpm.io/) — `npm install -g pnpm`

### Install Dependencies

```bash
pnpm install
```

### Development (Watch Mode)

Starts Tailwind in watch mode — rebuilds `output.css` automatically on every save.

```bash
pnpm run dev
```

Then open `public/index.html` in your browser (or use a local server like Live Server in VS Code).

### Production Build

Compiles and minifies `output.css` for deployment.

```bash
pnpm exec tailwindcss -i ./src/input.css -o ./public/css/output.css --minify
```

## ☁️ Deployment (Netlify)

This site is deployed on **Netlify** with automatic builds on every push.

| Setting | Value |
|---|---|
| **Build command** | `pnpm run build` |
| **Publish directory** | `public` |

> `output.css` is **gitignored** — Netlify generates it automatically during the build step.
